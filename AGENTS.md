# AncientBeast

The Turn Based Strategy Game/eSport. Master your beasts! 🐺

Package manager: npm.

## Commands

- build: `npm run build`
- test: `npm test`
- lint: `npm run lint`

## Layout

- `assets/`
- `src/`
- `static/`
- `types/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
